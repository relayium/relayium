⇌Relayium

가이드

Relayium으로 파일을 전송하는 모든 것 — 터미널 사용법, 휴대폰 간 전송, 다른 도구와의 솔직한 비교. 두 기기가 모두 온라인이면 Relayium으로 일회성 암호화 텍스트도 보낼 수 있습니다.

사용법

  • 안드로이드에서 아이폰으로 파일 전송하는 방법 (케이블 없이)
  • PC에서 폰으로 무선 파일 전송: 케이블도 앱도 필요 없이
  • 클라우드 없이 대용량 파일 보내는 방법
  • 만료되는 안전한 다운로드 링크로 파일 공유하기
  • 인터넷으로 컴퓨터 두 대 사이에 파일 보내는 방법
  • QR 코드를 스캔해서 파일 전송하기
  • 파일이 아니라 폴더째로 보내는 방법
  • cron 작업으로 암호화된 서버 백업 자동화하기
  • Windows·Linux·Android용 AirDrop 대안
  • Mac과 Windows PC 사이에서 파일 전송하는 방법
  • 같은 Wi-Fi에 있는 기기끼리 파일 보내기
  • 기기 사이에서 텍스트, 링크, 명령 보내기
