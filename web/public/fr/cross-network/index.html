⇌Relayium

Transfert de fichiers inter-réseaux, chiffré de bout en bout

Deux appareils sur des réseaux différents s'appairent avec un code à 6 chiffres (ou son lien/QR). Les fichiers circulent via un canal chiffré à travers le relais rapide de Relayium — le relais ne voit jamais que du contenu chiffré, les clés ne quittent jamais les deux appareils.

Démarrer le transfert

Transférer en quatre étapes

  1. L'expéditeur se connecte et génère un code d'appairage à 6 chiffres (ou partage son lien d'accès/QR).
  2. Le destinataire ouvre le lien ou saisit le code — aucun compte n'est nécessaire pour recevoir.
  3. Les deux parties vérifient le même code SAS à 6 chiffres à l'écran pour écarter tout homme du milieu.
  4. Les fichiers sont transférés chiffrés de bout en bout (AES-256-GCM par bloc) via le relais rapide de Relayium, qui ne transporte que du contenu chiffré qu'il ne peut pas lire.

Pourquoi Relayium

  • Chiffré de bout en bout — Échange de clés X25519 et AES-256-GCM par bloc ; les clés sont négociées uniquement entre les deux appareils, ni le relais ni le serveur ne peuvent donc déchiffrer.
  • SAS contre l'homme du milieu — Les deux écrans affichent le même code à 6 chiffres ; le faire correspondre déjoue même un relais ou un serveur de signalisation compromis.
  • Le relais ne voit que du chiffré — Les transferts inter-réseaux passent par un relais rapide pour garantir une connexion fiable à travers n'importe quel NAT — il ne transporte que du contenu chiffré, jamais vos clés ni du texte en clair.
  • Multiplateforme — Windows, macOS, Linux, Android, iOS — un navigateur moderne suffit, rien à installer.
  • Gratuit — Gratuit dans la limite d'un quota mensuel de trafic relais ; générer un code exige que l'expéditeur soit connecté, le destinataire rejoint de façon anonyme.

En comparaison

Face à AirDrop

AirDrop est réservé aux appareils Apple et à la proximité immédiate ; Relayium appaire Windows, Android, iPhone et Mac entre réseaux différents, chiffré de bout en bout, avec un simple navigateur.

Face à Snapdrop / PairDrop

Ceux-ci ne fonctionnent que sur le même réseau ; Relayium ajoute l'appairage inter-réseaux ainsi qu'un chiffrement de bout en bout au niveau applicatif et un code SAS, si bien qu'un relais ou un serveur de signalisation compromis ne peut pas espionner.

Questions fréquentes

Mes fichiers passent-ils par votre serveur ?

Le flux chiffré transite par le relais de Relayium pour garantir une connexion inter-réseaux fiable — mais tout est chiffré de bout en bout, donc le relais ne voit jamais que du contenu chiffré qu'il ne peut pas lire.

Un code est-il obligatoire ?

Oui : un code à 6 chiffres (ou son lien d'accès/QR), valable 15 minutes, appaire les deux appareils entre réseaux différents.

Faut-il un compte ?

L'expéditeur se connecte pour générer un code ; le destinataire rejoint de façon anonyme.

Est-ce chiffré de bout en bout ?

Oui — X25519 et AES-256-GCM par bloc, vérifié avec le code SAS ; ni le relais ni le serveur ne peuvent déchiffrer.
