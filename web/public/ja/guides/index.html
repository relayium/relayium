場面別ガイド

  • 同じ Wi-Fi 上の端末間でファイルを送る
  • インターネット経由で2台のPC間にファイルを送る方法
  • PC からスマホへ無線でファイル転送：ケーブルもアプリも不要
  • Android から iPhone へファイルを転送する方法（ケーブル不要）
  • Mac と Windows パソコン間でファイルを転送する方法
  • Windows・Linux・Android 向け AirDrop 代替
  • QR コードをスキャンしてファイルを転送する
  • ファイルではなくフォルダごと送る方法
  • 端末間でテキスト、リンク、コマンドを送る
  • クラウドを使わずに大きなファイルを送る方法
  • 期限付きの安全なダウンロードリンクでファイルを共有する

コマンドライン

  • Relayium CLI でターミナルからファイルとテキストを転送する
  • 常時稼働する Linux サーバーに Device Inbox を設定
  • Relayium CLI でネットワークを越えて誰かにファイルを送る
  • コマンドラインでファイルを受信する
  • 2台のサーバー間で大きなフォルダーを同期する（再開可能・バックグラウンド）
  • Relayium CLI でサーバー間転送（デーモン直結）
  • Relayium CLI と SSH で自分のサーバーにファイルをバックアップする
  • cron で暗号化されたサーバーバックアップを自動化する
  • クラウドにアップロードし、別のコンピュータで取得する

セルフホストと運用

  • Relayium をセルフホスト：自分専用のファイル・テキスト転送サーバーを運用
  • Bring Your Own Node: Relayium のリレー＆ストレージを無料で使う
  • Relayium を常時稼働の受信サービスとして実行する
