⇌Relayium

ファイルを暗号化リンクとして送る

相手がオンラインでないときは、今すぐアップロードしてリンクを共有しましょう。ブラウザはアップロード前に暗号化します。サーバーは復号できない暗号文だけを保持します——鍵はリンクから出ることはありません。

ファイルをアップロード

リンクができるまで

  1. サインインしてファイルを選びます——ブラウザが端末を離れる前にローカルで暗号化します。
  2. サーバーは暗号文だけを保存します。復号鍵はリンクのフラグメントにとどまり、サーバーに送信されることはありません。
  3. ダウンロードリンクを共有します（任意で閲覧後に削除、選んだ有効期限も設定できます）。
  4. 受信者がリンクを開くと、ブラウザが暗号文を取得し、リンク内の鍵で復号します。

この方法で送る理由

  • ゼロ知識 — ファイルはブラウザ内で暗号化されます。サーバーが持つのは復号できない暗号文だけです。
  • 鍵はリンクの中に — 復号鍵はURLフラグメント（#の後）に存在し、ブラウザはそれを決してサーバーへ送信しません。
  • 閲覧後に削除 + 有効期限 — 任意で初回ダウンロード後にファイルを削除でき、有効期限を設定すればその後は消えます。
  • 受信側にアカウント不要 — リンクを持つ誰でもダウンロードできます。サインインが必要なのはアップロードする側だけです。
  • 非同期モードとしての補完 — 相手が今オンラインでないときに使います。双方がオンラインならリアルタイムのクロスネットワーク転送を使ってください。
  • コマンドラインからも — ターミナルでは relayium up が同じリンクを表示してアップロードし、relayium down が別のマシンで取得します——CLI とウェブは同じリンクを共有します。

他の方法との比較

WeTransfer / Dropboxのリンクとの比較

それらはサーバー側でファイルを読むことができます。Relayiumのサーバーは復号できない暗号文だけを保持します——鍵は常にリンクの中にあります。

リアルタイムモードとの比較

リアルタイムモードは双方が同時にオンラインである必要があります。こちらは暗号化して保存するため、受信者は後から取得できます。

よくある質問

サーバーは私のファイルを読めますか？

いいえ——ファイルはブラウザ内で暗号化されます。サーバーは暗号文だけを保存し、鍵がサーバーに届くことはありません。

鍵はどこにありますか？

リンクのフラグメント（#の後）にあります。ブラウザはフラグメントをサーバーに送信しないため、完全なリンクを持つ人だけが復号できます。

アカウントは必要ですか？

アップロードには必要です（ストレージを使用するため）。ダウンロードには不要——リンクさえあれば十分です。

一度きりのダウンロードにできますか？

できます——閲覧後に削除を有効にし、有効期限も設定してください。
