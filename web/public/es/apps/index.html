¿Cuál debería usar?

  1. App web — sin instalación, en cualquier navegador moderno y en cualquier sistema operativo: archivos y texto efímero.
  2. Línea de comandos — transferencias de archivos programables, sincronización de carpetas, copias de servidores y texto efímero para macOS, Linux y Windows.
  3. App de macOS — descarga la app nativa de barra de menús, firmada y notarizada.
  4. App de iOS — una app nativa para iPhone y iPad: archivos y texto mientras está abierta; aún no disponible públicamente.

Una transferencia, todos tus dispositivos

  • App web — Nada que instalar. Ábrela en cualquier navegador moderno, en cualquier sistema operativo, para transferir archivos o enviar texto efímero.
  • Línea de comandos — Transferencias de archivos programables, sincronización de carpetas, copias de servidor a servidor y texto efímero para macOS, Linux y Windows.
  • App de macOS — Una auténtica app nativa en la barra de menús (com.relayium.mac): archivos y texto con dispositivos cercanos o por código de emparejamiento, enlaces cifrados para enviar y abrir, y gestión de cuenta y dispositivos. Disponible como descarga firmada y notarizada.
  • App de iOS — Una app nativa para iPhone y iPad (com.relayium.app): abre un enlace cifrado sin cuenta, envía archivos y texto a dispositivos cercanos o con un código de seis dígitos, y gestiona tu cuenta — mientras la app está abierta.
