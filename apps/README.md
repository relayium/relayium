# Relayium native apps

- `RelayiumKit/` — pure-logic Swift package (transport, signaling, crypto, wire). Test: `cd RelayiumKit && swift test`.
- `mac/` — macOS SwiftUI app (`com.relayium.mac`), depends on the local RelayiumKit package.

Golden crypto vectors live in `RelayiumKit/Tests/Fixtures/crypto-vectors.json`,
generated by `web/scripts/gen-crypto-vectors.mjs`. Regenerate on any crypto change.

## macOS app shell (deferred)

The SwiftUI `.app` under `apps/mac/` (bundle id `com.relayium.mac`) requires full
Xcode.app to create the project shell and Build & Run — this environment only has
the Command Line Tools. It will be created later on a machine with full Xcode,
adding the local `RelayiumKit` package as a dependency and rendering
`Text(RelayiumKit.sodiumReady() ? "core ready" : "core FAILED")` to prove the
package wires up end-to-end in the app target.

Until then, `swift test` on `RelayiumKit` (see above) is the toolchain proof:
it resolves `swift-sodium`, links libsodium, and runs a real crypto call.
